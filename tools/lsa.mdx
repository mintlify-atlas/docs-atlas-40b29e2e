---
title: "Lsa"
description: "Interact with the Windows Local Security Authority: look up names and SIDs, enumerate accounts, and manage privileges and system access rights."
---

The `Lsa` tool connects to the Local Security Authority on a remote Windows system and lets you translate account names to SIDs and back, enumerate LSA policy accounts and their privileges, create LSA accounts, and grant or revoke privileges and system access rights.

<Note>
The LSA tracks accounts separately from the SAM. Even for local accounts, you may need to create an LSA policy account first with [`createaccount`](#createaccount) before granting privileges.
</Note>

## Subcommands

| Command | Description |
|---|---|
| [whoami](#whoami) | Get the name and domain of the connected user |
| [lookupname](#lookupname) | Get the SID for one or more account names |
| [lookupsid](#lookupsid) | Translate one or more SIDs to their account names |
| [enumaccounts](#enumaccounts) | Enumerate LSA policy accounts |
| [enumprivaccounts](#enumprivaccounts) | Enumerate accounts that have a specific privilege or user right |
| [createaccount](#createaccount) | Create an LSA policy account |
| [getprivs](#getprivs) | Get the privileges assigned to an account |
| [getrights](#getrights) | Get the user rights and privileges granted to an account |
| [getsysaccess](#getsysaccess) | Get the system access rights granted to an account |
| [setsysaccess](#setsysaccess) | Set the system access rights granted to an account |
| [addpriv](#addpriv) | Add one or more privileges to an account |
| [rmpriv](#rmpriv) | Remove one or more privileges from an account |

<Note>
For help on any subcommand, run `Lsa <subcommand> -h`.
</Note>

## whoami

Returns the name and domain of the user account used to authenticate to the LSA.

```bash
Lsa whoami [options] <ServerName>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-OutputFields" type="string[]">
      Fields to display. Available: `WireName`, `UserName`, `Realm`, `OriginalText`, `NameType`, `NamePartCount`.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
Lsa whoami LUMON-FS1 -UserName milchick -Password Br3@kr00m!
```

<AccordionGroup>

## enumaccounts

Enumerates accounts in the LSA policy database. By default returns only SIDs. Use `-OutputFields` to include account and domain names, which requires additional RPC calls.

```bash
Lsa enumaccounts [options] <ServerName>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-OutputFields" type="string[]">
      Fields to display. Available: `Sid`, `AccountName`, `DomainName`.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
# List account SIDs only
Lsa enumaccounts LUMON-FS1 -UserName milchick -Password Br3@kr00m!

# Include account and domain names
Lsa enumaccounts LUMON-FS1 -UserName milchick -Password Br3@kr00m! -OutputFields Sid,AccountName,DomainName
```

## getprivs

Gets the privileges assigned to an account. Specify the account by SID (`-BySid`) or name (`-ByName`). One of these options is required.

By default, only the names of well-known privileges are resolved. To retrieve names for all privileges, add `PrivilegeName` to `-OutputFields`.

```bash
Lsa getprivs [options] <ServerName>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-BySid" type="SecurityIdentifier">
      SID of the account.
    </ParamField>
    <ParamField path="-ByName" type="string">
      Name of the account.
    </ParamField>
    <ParamField path="-OutputFields" type="string[]">
      Fields to display. Available: `Privilege`, `Attributes`, `PrivilegeName`.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
# Look up by SID
Lsa getprivs LUMON-FS1 -UserName milchick -Password Br3@kr00m! -BySid S-1-5-32-544

# Look up by name
Lsa getprivs LUMON-FS1 -UserName milchick -Password Br3@kr00m! -ByName Administrator

# Include resolved privilege names
Lsa getprivs LUMON-FS1 -UserName milchick -Password Br3@kr00m! -ByName Administrator -OutputFields Privilege,PrivilegeName
```

## setsysaccess

Sets the system access rights granted to an account. By default, the specified rights are added to any already granted. Use `-Reset` to clear existing rights and grant only the rights specified. To remove all rights, use `-Reset` with `0`.

System access rights include logon rights such as `SeInteractiveLogonRight` and `SeServiceLogonRight`.

```bash
Lsa setsysaccess [options] <ServerName> <Rights>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
    <ParamField path="Rights" type="SystemAccessRights[]" required>
      Access rights to grant. Possible values: `SeInteractiveLogonRight`, `SeNetworkLogonRight`, `SeBatchLogonRight`, `SeServiceLogonRight`, `SeDenyInteractiveLogonRight`, `SeDenyNetworkLogonRight`, `SeDenyBatchLogonRight`, `SeDenyServiceLogonRight`, `SeRemoteInteractiveLogonRight`, `SeDenyRemoteInteractiveLogonRight`.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-BySid" type="SecurityIdentifier">
      SID of the account.
    </ParamField>
    <ParamField path="-ByName" type="string">
      Name of the account.
    </ParamField>
    <ParamField path="-Reset" type="boolean">
      Clear any existing rights before applying the specified ones.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
Lsa setsysaccess LUMON-FS1 -UserName milchick -Password Br3@kr00m! -BySid S-1-5-32-544 SeBatchLogonRight
Lsa setsysaccess LUMON-FS1 -UserName milchick -Password Br3@kr00m! -ByName Administrators SeBatchLogonRight
```

## addpriv

Adds one or more privileges to an account. Specify the account by SID (`-BySid`) or name (`-ByName`).

Privilege names can be symbolic (e.g. `SeLoadDriverPrivilege`) or numeric 64-bit integers. For predefined privileges, you may omit the `Privilege` suffix (e.g. `SeLoadDriver` instead of `SeLoadDriverPrivilege`). If the name is not predefined, it is resolved with the remote LSA.

<Warning>
This command cannot be used to grant user rights (logon rights). Use [`setsysaccess`](#setsysaccess) for that.
</Warning>

```bash
Lsa addpriv [options] <ServerName> <Privileges>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
    <ParamField path="Privileges" type="string[]" required>
      Names or numeric values of the privileges to add. Examples: `SeLoadDriverPrivilege`, `SeTcbPrivilege`, `SeDebugPrivilege`, `SeBackupPrivilege`, `SeRestorePrivilege`, `SeImpersonatePrivilege`.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-BySid" type="SecurityIdentifier">
      SID of the account.
    </ParamField>
    <ParamField path="-ByName" type="string">
      Name of the account.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
# Add privileges by account name
Lsa addpriv LUMON-FS1 -UserName milchick -Password Br3@kr00m! -ByName Administrators SeLoadDriver SeTcb

# Add privileges by SID
Lsa addpriv LUMON-FS1 -UserName milchick -Password Br3@kr00m! -BySid S-1-5-32-646 SeLoadDriver SeTcb
```

## rmpriv

Removes one or more privileges from an account. To remove all privileges, specify `*` (escape as needed in your shell). Specify the account by SID (`-BySid`) or name (`-ByName`).

<Warning>
This command cannot be used to remove user rights (logon rights).
</Warning>

```bash
Lsa rmpriv [options] <ServerName> <Privileges>
```

<AccordionGroup>
  <Accordion title="Parameters">
    <ParamField path="ServerName" type="string" required>
      RPC server to interact with.
    </ParamField>
    <ParamField path="Privileges" type="string[]" required>
      Names or numeric values of the privileges to remove. Use `*` to remove all privileges.
    </ParamField>
  </Accordion>

  <Accordion title="Options">
    <ParamField path="-BySid" type="SecurityIdentifier">
      SID of the account.
    </ParamField>
    <ParamField path="-ByName" type="string">
      Name of the account.
    </ParamField>
  </Accordion>
</AccordionGroup>

### Examples

```bash
# Remove a privilege by account name
Lsa rmpriv LUMON-FS1 -UserName milchick -Password Br3@kr00m! -ByName Administrators SeTcb

# Remove a privilege by SID
Lsa rmpriv LUMON-FS1 -UserName milchick -Password Br3@kr00m! -BySid S-1-5-32-646 SeTcb

# Remove all privileges
Lsa rmpriv LUMON-FS1 -UserName milchick -Password Br3@kr00m! -BySid S-1-5-32-646 "*"
```
